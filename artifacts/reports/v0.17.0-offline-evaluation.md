## Limitations

- 30 examples total (15 task classes x 2 iterations) is a very small dataset.
- Train/test split by task class means the test partition has only 3 task classes.
- Logistic regression on 7 features may overfit or underfit with this sample size.
- The learning label (pro-necessary = Flash fail AND Pro pass) is binary; a utility-based
  delta-U label capturing cost/latency tradeoffs would be richer.
- No cross-validation; a single train/val/test split has high variance with 30 examples.
- The heuristic router also has mid-turn escalation and step-retention logic not modeled here.
- This is offline evaluation only; no live runs. v0.17.1 should run shadow mode.

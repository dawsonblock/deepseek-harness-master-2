# v0.17.3 Pro-Necessity Forensic Analysis

Dataset: paired-v4-100-v1

## Label audit

- 3 genuine rescues, 1 ambiguous rescue, and 2 verifier artifacts.
- 5 of 6 rescue prompts have another identical-prompt iteration where Flash passes.
- Tool and repair counts are available, but the benchmark does not retain individual tool payloads or provider reasoning text.

| Task | Label validity | Failure mechanism | Why Flash failed | What Pro did differently | Missing V2 signal |
|---|---|---|---|---|---|
| constraints-email/1 | genuine | extraneous-output-and-terminal-format-violation | Added an introduction, separators, and a postscript; exceeded the word limit and did not end with the exact signature. | Returned only the email body, stayed below 50 words, and ended with the exact literal signature. | Explicit constraint count, maximum length, exact terminal literal, and no-extraneous-output requirement. |
| json-filter/1 | genuine | projection-schema-and-exact-format-error | Returned an array of strings inside a code fence instead of objects containing only the name field. | Applied filtering and object projection while preserving the requested JSON object schema without a fence. | Transformation operation count, output object cardinality, output field count, and strict unfenced JSON. |
| plan-api/1 | verifier-artifact | numbered-step-verifier-markup-sensitivity | The verifier ignored five semantically numbered steps because each number was wrapped in Markdown bold syntax. | Used plain line-leading numbers that matched the verifier regular expression. | None; the verifier must recognize equivalent Markdown numbering. |
| synthesis-oauth/1 | genuine | required-cardinality-collapse | Collapsed four requested role sentences into one compound semicolon-delimited sentence. | Produced one independent sentence for each of the four roles. | Source entity count, one-output-unit-per-entity constraint, and expected output cardinality. |
| constraints-table/1 | ambiguous | extraneous-restatement-breaks-exact-multiplicity | The table was correct, but a trailing explanation repeated every owner and priority, breaking exact-once checks. | Returned the table without a trailing restatement. | Exact multiplicity constraints, output-only requirement, and extraneous-text prohibition. |
| plan-migration/1 | verifier-artifact | top-level-step-verifier-counting-error | The answer contained six Step headings, but the verifier counted only line-leading digit-dot syntax. | Also used Step headings; nested numbered cutover actions accidentally made the regex count equal six. | None; the verifier must count top-level plan steps instead of unrelated nested numbers. |

## Consequence

The six raw rescue labels are not six independent, deterministic examples of latent Pro necessity. Two are verifier artifacts, one is verifier-sensitive, and five conflict with a Flash-pass observation at the same pre-routing task structure. V2 training keeps label validity separate and does not treat verifier artifacts as positive routing targets.
